# Team Configuration

## Purpose

Rules follow teams. Team setup and rule setup must be configured together.

## Team configuration areas

Each team should expose:

- **Identity** — name, core group, active status
- **Squad settings** — target squad size, max squad size, support priority
- **Selection rules** — own-core preference, support priority, floating gap, squad size cap, match load fairness, core match drop allowance if implemented
- **Notes** — explanation that rules may be global but this page shows how they affect this team

## Rules ownership

Rules may be global in implementation, but the UX must expose team-relevant rules from the team configuration surface.

## Coherent shop

The coach should not have to jump between Teams and Rules to understand how a team behaves in selection.
