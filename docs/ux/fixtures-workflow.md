# Fixtures Workflow

## Purpose

Fixtures is the match planning surface. It shows matches grouped by period and round, with actions available at period, round, and match level.

## Page structure

Fixtures page groups:

- Period
  - Round
    - Matches

## Period actions

- View period
- Generate all missing round drafts if supported
- Recalculate period if supported
- Show period readiness summary

## Round actions

- Open round review
- Generate round selection
- Recalculate round
- Show readiness
- Show unresolved issues
- Show publish status

## Match actions

- Open match review
- Open match selection
- Open post-match
- Show match readiness
- Show selected player count
- Show unresolved issues

## Naming

- Use "Fixtures" for the menu and page.
- Use "Round Review" for round-level selection review.
- Use "Match Review" for single-match review.
- Do not use "Matches" as a redirect to rounds.
